# 다온펫살롱 마을 (v5)
실행: `cd daon-village && npm install && node server.js` → http://localhost:8765
- PORT=xxxx 로 포트 변경. 서버 없이 index.html만 열면 '혼자 모드'.
- 내용 수정: config.js

## v4 (걷기 애니메이션 + 미용 스타일)
- `dogs.js`: 강아지를 몸통·머리·귀·꼬리·다리 4개로 코드로 그려서 견종×스타일×방향(앞/뒤/옆)×프레임(서있기 + 걷기 6장)을 캐시합니다. 다리만 움직여서 모든 프레임이 같은 그림입니다. 왼쪽은 오른쪽을 뒤집어서 씁니다.
- `dogdata.js`: 견종·미용스타일 목록(브라우저와 서버가 같이 씀). 견종/스타일을 추가하려면 여기와 `dogs.js` 의 `B`(견종 기본값)·`S`(스타일 값)를 고치세요.
- 서버(`server.js`)는 접속할 때 받은 `style` 을 견종별 허용 목록으로 검사하고, 틀리면 그 견종의 기본 스타일로 바꿔요.

## v5 (싸이월드 미니룸 · 미니미 도트 스타일)
- 그림 파일 없이 전부 코드로 그리는 도트 아트예요. `pix.js`(도트 버퍼·마스크 도구), `dogs.js`(큰 머리 미니미 강아지: 견종×스타일×앞/뒤/옆×걷기 6프레임), `art.js`(살롱 건물·울타리·꽃밭·길·실내·원장님 NPC).
- 월드는 도트 단위(한 칸=16도트)이고 정수 배율로 확대해 또렷하게 그려요(imageSmoothingEnabled=false). 말풍선·이름표는 별도 화면 레이어.
- 3/4 탑다운 시점이라 타일 이동·길찾기·멀티플레이는 그대로예요. 저장 키 `daonVillage3` 유지(`v:5` 이전 저장은 위치만 초기화).
- 창틀(파스텔 하늘/분홍 도트 프레임)은 `game.js` 의 `frameURL` 이 만들어 `--f-*` CSS 변수로 쓰고, `style.css` 가 꾸며요.
- `assets/` 에는 글꼴(`jua.woff2`)만 남았어요. v4 전체는 git 기록에 있어요.
